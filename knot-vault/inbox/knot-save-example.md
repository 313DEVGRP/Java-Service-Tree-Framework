# knot save 예시 메모

inbox에 자료를 넣는 형식 예시. ingest가 이 파일을 읽고 wiki 페이지로 컴파일한다.

## 형식은 자유

정해진 틀이 없다. 평문 메모, 회의록, 붙여넣은 로그, URL 목록 다 된다.
ingest 단계에서 에이전트가 읽고 source/entity/concept 페이지로 구조화한다.
따라서 inbox 파일은 "나중에 내가 읽어도 무슨 자료인지 알 수 있는" 수준이면 충분하다.

## 넣으면 좋은 것

- 자료의 출처 (URL·회의 일시·누가 말했는지)
- 왜 저장하는지 한 줄 — 나중에 ingest가 맥락을 잡는 데 쓰인다
- 원문 그대로의 인용 (요약은 ingest가 한다)

## 지속가치 기준

knot은 "지속가치 있는 지식"을 담는 곳이다. 이번 대화에서만 쓰이는 임시 메모,
코드에 이미 적혀 있는 사실, git 이력이 기록하는 내용은 넣지 않는다.
판단이 애매하면 넣어두고 ingest 때 걸러도 된다 — inbox는 큐일 뿐이다.
